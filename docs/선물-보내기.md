# 선물 보내기

운영자가 유저에게 도구·돈·볼을 주는 방법. **받는 사람에게 창이 떠서
알려 준다.**

## 가방을 직접 고치면 안 된다

```sql
UPDATE bag SET count = count + 1 WHERE ...   -- 이러면 알림이 안 뜬다
```

이렇게 넣으면 물건은 들어가지만 **유저는 그게 늘어난 줄 모른다.** 가방은
드랍·판매·배틀 보상으로도 늘어나므로, 서버가 "이건 선물이다" 를 구분할
방법이 없기 때문이다.

선물은 `gift` 표에 넣는 것이 **유일한 길**이다. 서버가 그걸 보고 지급
하면서 알린다.

## 어떻게 도는가

```
운영자가 gift 에 INSERT
        ↓
유저가 접속 (90초마다 /api/me 를 부른다)
        ↓
서버가 안 받은 선물을 지급하고 claimed_at 을 찍는다
        ↓
클라이언트가 창을 띄운다
```

같은 흐름에서 지급과 표시를 끝내므로 **두 번 주지 않는다.** 여러 번
돌려도 안전하다.

## 서버 DB 에 붙기

```bash
ssh -i <키> ubuntu@<고정IP>
docker exec -it poketdesktop-server python3
```

또는 `bash deploy/dbview.sh --write` 로 브라우저에서.

## 한 명에게

```sql
INSERT INTO gift (user_id, kind, item_id, count, title, message, created_at)
VALUES (39, 'item', 'FLOWERBALL', 1,
        '50명 기념 선물', '함께해 주셔서 고맙습니다!',
        strftime('%Y-%m-%dT%H:%M:%S+00:00', 'now'));
```

`kind` 는 셋 중 하나다.

| kind | 무엇 | 쓰는 칸 |
|---|---|---|
| `item` | 가방에 들어가는 도구 | `item_id` + `count` |
| `money` | 소지금 | `count` (원) |
| `balls` | 몬스터볼 | `count` (개) |

`item_id` 는 `items.json` 의 키다 (`FLOWERBALL`, `RARECANDY`,
`MASTERBALL` …).

## 전원에게

```sql
INSERT INTO gift (user_id, kind, item_id, count, title, message, created_at)
SELECT id, 'item', 'FLOWERBALL', 1,
       '50명 기념 선물', '함께해 주셔서 고맙습니다!',
       strftime('%Y-%m-%dT%H:%M:%S+00:00', 'now')
FROM users;
```

## 지금까지 가입한 사람에게만

이벤트를 '기념' 으로 두고 싶을 때. 시각을 넣거나 id 로 자른다.

```sql
-- 이 시각 전에 가입한 사람만
... FROM users WHERE created_at < '2026-09-10T00:00:00+00:00';

-- 또는 id 로
... FROM users WHERE id <= 120;
```

## 넣고 나서 확인

```sql
-- 아직 안 받은 것
SELECT g.id, u.username, g.kind, g.item_id, g.count
FROM gift g JOIN users u ON u.id = g.user_id
WHERE g.claimed_at IS NULL;

-- 받아 간 것
SELECT COUNT(*) FROM gift WHERE claimed_at IS NOT NULL;
```

**켜 두지 않은 사람은 다음에 켤 때 받는다.** 안 받은 채로 남아 있는
것이 정상이다.

## 잘못 넣었을 때

아직 안 받았으면 지우면 된다.

```sql
DELETE FROM gift WHERE id = 12 AND claimed_at IS NULL;
```

**이미 받아 간 것은 지워도 소용없다.** 물건은 이미 가방에 있다.
그때는 가방을 직접 줄이는 수밖에 없다.

## 이벤트 볼과 얽힌 것

`FLOWERBALL` 은 그냥 도구가 아니다. **이 볼을 가진 사람에게만 이벤트
풀숲(꽃이 핀 것)이 돋는다.** 볼을 준 것 자체가 이벤트 명단이라, 명단을
따로 두지 않는다.

- 볼을 받은 사람 → 잡을 때까지 꽃 핀 풀숲이 반드시 돋는다
- 볼이 없는 사람 → 평소대로 놀다 아주 가끔 만난다 (`POKET_EVENT_RESPAWN`,
  기본 0.2%)

그래서 **새로 가입한 사람에게는 볼을 안 주는 것이 기본**이다. 주면
그 사람도 이벤트 대상이 된다.
